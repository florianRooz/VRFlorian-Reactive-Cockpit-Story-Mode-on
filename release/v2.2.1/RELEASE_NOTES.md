This is the repaired clean installer for new VRFlorian Reactive Cockpit open-test players.

It contains Story Mode ON, Living World, Mission 1, Mission 2, the complete local story-media map, the altitude-exit hardening, Florian's final Mission 2 objective/audio polish, Disco Mode, and the permanently repaired automatic updater.

New players should download `VRFlorian_Reactive_Cockpit_V2.2.1.zip`, extract the complete folder, and run `START VRFLORIAN REACTIVE COCKPIT.bat`.

Existing V2.2.0 players should not replace their installation with this full package. Apply the one-time V2.2.0 updater bootstrap, then use **CHECK FOR UPDATES** in the launcher; mission progress, cockpit assignments and configuration are preserved.
