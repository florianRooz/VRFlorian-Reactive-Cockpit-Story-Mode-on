VRFLORIAN REACTIVE COCKPIT — VERSION 2.2.1 OPEN TEST
====================================================

Thank you for trying VRFlorian Reactive Cockpit.

FIRST INSTALL
-------------

1. Extract the complete "VRFlorian Reactive Cockpit" folder to a normal,
   writable location. Do not run it from inside the ZIP.
2. Double-click:

       START VRFLORIAN REACTIVE COCKPIT.bat

3. Install Python and EDHM when the launcher asks, if they are not already
   installed.
4. Select a cockpit and the ship on which you want to install it. Repeat this
   for every ship that should have a Reactive Cockpit.
5. Keep EDHM UI closed while Reactive Cockpit is running.
6. Click ACTIVATE. The launcher closes and Reactive Cockpit starts.

STORY MODE ON
-------------

Story Mode ON is the single-player campaign mode inside Reactive Cockpit: a
fun, non-lore, fully scripted adventure across some of Elite Dangerous' deeper
layers and unique locations.

1. Install at least one cockpit, then use the large red STORY MODE button to
   switch Story Mode ON.
2. STORY MODE OPTIONS appears in the upper-right corner.
3. Living World is the default. No campaign mission is active, but certain
   locations can still contain additional sound, visual effects and mysteries.
4. Select SET ACTIVE beside Mission 1 or Mission 2 to begin or resume it.
5. Enter the game and travel to Sol. The selected mission begins after the game
   publishes your live location.
6. Progress is saved at checkpoints. Turning Story Mode OFF pauses the story;
   it does not erase progress.
7. The Story Reader shows one current clue, scanner status and, where relevant,
   location windows and remaining scan areas.

RESET creates a dated backup of that mission's current save before returning
the mission to its beginning.

TURN ELITE DANGEROUS NATIVE MUSIC OFF when playing MISSION 2 (It has custom music).

DISCO MODE
----------

Press CTRL+SHIFT+D while Reactive Cockpit is active to start or stop Disco
Mode. Eight coordinated cockpit-lighting combinations cycle every two seconds.
Disco Mode can substantially increase GPU load, so it is intended for short
bursts rather than continuous use. It always starts OFF after a new launch.

UPDATES
-------

Use CHECK FOR UPDATES in the launcher. Published downloads are verified by
file size and SHA-256 before installation. Updates preserve cockpit assignments,
machine-specific configuration, mission progress, runtime state and logs.
